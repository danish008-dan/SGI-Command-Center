Result Management Workflow

Here is the complete step-by-step process of how Results are managed in SGI Command Center:

  • 1. Marks Entry (Teacher): Teachers enter marks for students. Marks are saved as 'Draft' until submitted for verification.
  • 2. Marks Verification (HOD): HOD reviews the submitted marks and either 'Verifies' them or 'Returns' them for correction. Only 'Verified' marks are used for result calculation.
  • 3. Generate Draft (Admin): The Admin selects a semester and clicks 'Generate (Draft)'. The system calculates SGPA, CGPA, and Grades based on verified marks. Results are saved as 'Draft'.
  • 4. Submit to Principal (Admin): The Admin clicks 'Submit to Principal'. The results status changes to 'Pending Principal'. The Principal must now review and approve.
  • 5. Principal Approval: The Principal logs in, reviews the pending results, and clicks 'Approve'. The results status changes to 'Approved'.
  • 6. Publish (Admin): The Admin clicks 'Publish'. The results status becomes 'Published' and students can now view their results on their portal.
  • 7. Retraction (Admin): If a correction is needed after publishing, the Admin clicks 'Retract (Correct)'. The result goes back to 'Draft' status, and the approval process restarts.
  • 8. Revaluation: If a student requests a revaluation, the Admin updates the marks. The old result is saved in history, and the new result goes back to 'Draft' for re-approval.
